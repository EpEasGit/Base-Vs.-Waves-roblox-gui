# Base-Vs.-Waves-roblox-gui
This gui includes the following features: automatic wave starting, after this happens you can also spawn units during waves
ability to switch maps, even to ones you havent been to yet
super OP unit spawner: allows you to select the current map and which slot you want it placed on (like which tower, sandbag, trench) it lets you pick between a few units that you can spawn
these units save and are permanent, you can pick them up so you basically just duped them, they stack so you can spam spawn them on every square for the ultimate defense
